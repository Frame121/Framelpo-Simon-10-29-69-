Background music for Html.html
==============================

The published page uses this mobile-friendly MP3:
  assets\ParPar - OYY (Official Lyric Video).mp3

It is extracted from the provided WebM source and encoded as stereo MP3,
160 kb/s, 44.1 kHz, duration 3:21.48. The original WebM is kept locally
but intentionally not included in the published Git repository because
the web page uses the MP3 track only.

Html.html / index.html load this file after the user presses the Read Letter
button. It plays at 10% background volume and loops. Keep this MP3 inside the
assets folder and preserve the relative path when publishing. Playback may
require a user tap in mobile browsers.
