# Simon — Happy 5 Months 💜

เว็บครบรอบ 5 เดือนแบบหน้าเดียว ใช้ HTML, CSS และ JavaScript พร้อมแกลเลอรีรูปและเพลงพื้นหลัง

## เปิดใช้งาน
- เปิด index.html ในเบราว์เซอร์
- รูปทั้งหมดอยู่ใน photo/
- รูปโปรไฟล์อยู่ที่ f.png และ s.png
- เพลงใช้ assets/ParPar - OYY (Official Lyric Video).mp3

## เผยแพร่ผ่าน GitHub Pages
ใน GitHub ไปที่ Settings → Pages แล้วเลือก Deploy from a branch, branch main, folder / (root) จากนั้นบันทึก

หมายเหตุ: เพลงจะเริ่มหลังผู้ใช้แตะปุ่มอ่านจดหมาย เพราะข้อจำกัดการเล่นเสียงอัตโนมัติของเบราว์เซอร์มือถือ ต้องอัปโหลดโฟลเดอร์ photo/ และ assets/ ตามโครงสร้างเดิมด้วย
